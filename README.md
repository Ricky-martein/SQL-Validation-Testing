# SQL Validation Testing Project

## Project Overview
This project demonstrates SQL-based data validation testing for QA purposes.

## Testing Scope
- Data validation
- NULL value checks
- Duplicate record checks
- JOIN validation
- Aggregation validation
- Business rule validation

## SQL Concepts Used
- SELECT
- WHERE
- ORDER BY
- GROUP BY
- HAVING
- JOIN
- COUNT
- NULL checks

## Tools Used
- SQLBolt
- DB Fiddle
- GitHub
